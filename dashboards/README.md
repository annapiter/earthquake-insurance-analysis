# Earthquake Underinsurance Dashboard (Tableau)

This directory documents the Tableau dashboard for the project  
**“Earthquake Insurance Risk Analysis in California (2023).”**

The dashboard provides an interactive view of:
- County-level underinsurance tiers  
- Financial exposure estimates  
- Model-predicted vs. actual take-up rates  
- Top underinsured counties  
- Executive KPIs and summary visualizations  

## 🔗 Live Dashboard (Tableau Public)

👉 [California Earthquake Underinsurance 2023 Dashboard](https://public.tableau.com/app/profile/annapiter/viz/CaliforniaEarthquakeUnderinsurance2023ModelAnalysis/CaliforniaEarthquakeUnderinsurance2023)

The Tableau Public version is the preferred way to explore the dashboard.


## Notes

- The dashboard uses processed outputs from the `output/` directory and models documented in `notebooks/`.
- Colors follow the project palette (teal `#18A8A1`).
- The live Tableau Public version is always the most up-to-date and user-friendly view.
